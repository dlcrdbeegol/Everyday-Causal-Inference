# Everyday Causal Inference - Study Repository

This repository contains study materials and exercises for the **Everyday Causal Inference** book.

## Purpose

This repository is dedicated to learning and mastering the concepts of causal inference through hands-on exercises, notebooks, and practical examples from the Everyday Causal Inference book.

## Contents

- **Jupyter Notebooks**: Interactive notebooks covering key topics from each chapter
- **Data**: Sample datasets used throughout the course
- **Exercises**: Practical problems and solutions

## Getting Started

1. Clone or download this repository
2. Install required dependencies (pandas, statsmodels, etc.)
3. Open the Jupyter notebooks to explore the chapters and exercises

## Structure

Each chapter includes:
- Explanatory notebooks with code examples
- Practice problems and solutions
- Dataset files for analysis

## Requirements

- Python 3.8+
- pandas
- statsmodels
- Other dependencies as specified in individual notebooks

## About

This study material is based on the **Everyday Causal Inference** book and is used for personal learning and understanding causal inference methodologies.
